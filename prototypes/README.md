# Три навчальні прототипи

Кожний файл запускається окремо з кореня репозиторію. Усі три використовують
спільні `src/dungeon_escape/model.py` та `app.py`, але різні конфігурації рівня.
Це три експерименти з механіками, а не три послідовні рівні готової кампанії.

| Прототип | Навчальна гіпотеза | Карта й відмінності | Що перевіряємо |
| --- | --- | --- | --- |
| 1. Ключ і вихід | Однієї залежності «знайти ключ → повернутися до виходу» досить для задачі на маршрут | Лабіринт 15 × 11, ключ унизу, ворога немає | Рух, стіни, збирання, замкнений вихід, перемога |
| 2. Патруль | Передбачувана рухома загроза додає вибір моменту переходу | Кімната 15 × 9, патруль поперек середини, крок 0,45 с | Очікування, зіткнення з обох боків, поразка, повторна спроба |
| 3. Втеча з підземелля | Навігація й патруль можуть працювати разом на компактному рівні | Геометрія лабіринту з прототипу 1, ключ перенесено, патруль у нижньому коридорі, крок 0,60 с | Повний цикл «дослідження → ключ → безпечний вихід» |

Технічна працездатність перевірена. Гіпотези про цікавість і складність
потребують спостереження за людьми й не вважаються доведеними тестами.

## Прототип 1 — ключ і вихід

```bash
python prototypes/01_key_and_exit.py
```

![Лабіринт без ворога](../presentation/images/prototype-01.png)

Сценарій: натиснути Enter; перевірити, що стіна не пропускає; відшукати золотий
ключ; повернутися до виходу «В». Ключ після підбирання зникає, а вихід зеленіє.
За бажанням спершу дійти до виходу без ключа: він має показати підказку, а не перемогу.
Завершення — екран «Перемога!», R повертає початковий стан.

## Прототип 2 — патруль

```bash
python prototypes/02_enemy_patrol.py
```

![Кімната з патрулем](../presentation/images/prototype-02.png)

Сценарій: спостерігати за рухом червоного квадрата вздовж точок посеред кімнати;
перетнути його маршрут, забрати ключ унизу ліворуч і повернутися до виходу вгорі
праворуч. Для окремої перевірки поразки зайти на клітинку ворога або дочекатися
його на маршруті. Після поразки патруль має завмерти. R відновлює спробу.

## Прототип 3 — об’єднаний рівень

```bash
python prototypes/03_dungeon_escape.py
```

![Лабіринт із патрулем](../presentation/images/prototype-03.png)

Сценарій: пройти ліву частину лабіринту до нижнього коридору, спостерігати за
патрулем, дістатися проходу в центральну частину, забрати ключ і знайти вихід.
Можна обрати безпечніший обхід. Карта не вимагає обов’язкового контакту з ворогом.

## Спільні обмеження

Немає плавної анімації, звуку, переслідування, випадкової генерації чи переходу
між прототипами всередині вікна. Фігури виконують роль тимчасової графіки.
Показані маршрути патруля — допоміжна візуалізація прототипу.
Прототип 1 не має умови поразки; це навмисне ізолювання механіки ключа.
Вихід без ключа можна перетнути, але завершити гру на ньому неможливо.

Команди автоматичної перевірки та їхні результати наведено у
[звіті](../docs/validation.md). Живий показ потребує графічного сеансу.
