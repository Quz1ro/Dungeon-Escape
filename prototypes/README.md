# Початкові прототипи

На першому етапі перевірялися три механіки:

1. Ключ і вихід — рух, стіни й умова перемоги.
2. Патруль — рух ворога, зіткнення та повторна спроба.
3. Лабіринт із патрулем — поєднання навігації та небезпеки.

Початкові карти збережено у `src/dungeon_escape/levels.py`, правила — у `model.py`.
Старі файли запуску залишено для сумісності: тепер вони відкривають головне меню
актуальної гри. Основна точка запуску — `python main.py` або `run.bat`.

Нова версія має окремі кампанії по 9 рівнів; їхні карти й правила розташовані
у `src/dungeon_escape/campaign.py`.
