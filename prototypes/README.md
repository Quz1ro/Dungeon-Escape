# Прототипи

Прототипи запускаються окремо з кореня репозиторію. У них спільна логіка,
але різні карти та набори механік.

## 1. Ключ і вихід

```bash
python prototypes/01_key_and_exit.py
```

Лабіринт 15 × 11 без ворога. Перевіряє рух, стіни, підбирання ключа
та умову перемоги. Ключ лежить у нижній частині карти, вихід — угорі праворуч.
Без ключа вихід показує повідомлення про замок.

## 2. Патруль

```bash
python prototypes/02_enemy_patrol.py
```

Кімната 15 × 9 із патрулем посередині. Потрібно перетнути його маршрут,
забрати ключ унизу ліворуч і повернутися до виходу. Перевіряє рух ворога,
зіткнення, поразку й перезапуск. Інтервал кроку охоронця — 0,45 с.

## 3. Втеча з підземелля

```bash
python prototypes/03_dungeon_escape.py
```

Лабіринт із перенесеним ключем та патрулем у нижньому коридорі.
Поєднує механіки попередніх прототипів. Інтервал кроку охоронця — 0,60 с.

Для всіх прототипів: Enter — почати, стрілки або WASD — рух,
R — спочатку, Esc — вихід.
