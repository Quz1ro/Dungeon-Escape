# Dungeon Escape

Навчальна 2D-гра на Python і Pygame для курсу «Розробка ігрових додатків».
Знайдіть ключі, відкрийте двері та виберіться з лабіринту.

![Головне меню](presentation/images/menu.png)

## Режими

- **Рівні:** 9 лабіринтів для одного гравця.
- **Гра на двох:** 9 лабіринтів для двох гравців на одній клавіатурі.

Номери рівнів розташовані сіткою 3 × 3. Вибір — мишею або стрілками та Enter.
Усі рівні доступні відразу, пройдені позначаються окремо для кожного режиму.

У грі на двох синій гравець керується стрілками, рожевий — WASD.
У кожного своя половина лабіринту, власні ключі, двері й вихід.
Перемога — коли вийшли обидва. Якщо охоронець упіймає одного, спробу потрібно
почати заново. Гравець, який уже вийшов, безпечно чекає напарника.

## Ключі та двері

- **Круглий ключ** відкриває одні двері свого кольору й витрачається.
- **Ключ-ромб** потрібен для завершення рівня через власний вихід.
- Чужі ключі не підбираються; чужі замкнені двері відкрити не можна.
- Червоні квадрати — охоронці, контакт із ними означає поразку.

Наступні рівні мають довший основний маршрут: від 54 до 86 кроків на гравця.
Кількість дверей зростає від одних до трьох, патрулів — від нуля до трьох
на половину карти, а інтервал їхнього кроку зменшується. Карти фіксовані:
повторний запуск не змінює лабіринт. Складність для людей ще потребує ігрових спроб.

## Запуск

Потрібен Python 3.10+; рекомендовано **Python 3.12**.

**Windows:** розпакуйте проєкт і відкрийте `run.bat`. Він створить середовище,
встановить Pygame й запустить гру. Для першого запуску потрібен інтернет.

Ручний запуск із кореня проєкту:

```bash
python -m venv .venv
```

Активація: `source .venv/bin/activate` у Linux / macOS,
`.venv\Scripts\Activate.ps1` у Windows PowerShell.

```bash
python -m pip install -r requirements.txt
python main.py
```

## Керування

| Клавіші | Дія |
| --- | --- |
| Стрілки / WASD | Рух в одиночній грі |
| Стрілки | Гравець 1 у грі на двох |
| WASD | Гравець 2 у грі на двох |
| P | Пауза / продовжити |
| R | Почати рівень заново для обох гравців |
| M | Вибір рівня |
| Enter після перемоги | Наступний рівень |
| Esc | Назад; у головному меню — вихід |

Вікно можна змінювати за розміром. Прогрес зберігається локально у
`.cache/dungeon_escape/progress.json`. Видалення цього файла скидає позначки проходження.

## Перевірка

```bash
python -m unittest discover -s tests -v
```

**41 тест пройдено.** Перевірено прохідність усіх 18 карт, особисті ключі,
двері, спільну перемогу, незалежне керування, паузу й збереження прогресу.
Перевірка графіки виконана через SDL `dummy`, без фізичного дисплея.
