# Перевірка роботи

Середовище: Linux, Python 3.12, Pygame 2.6.1, SDL `dummy`.

```bash
python -m unittest discover -s tests -v
```

**53 тести пройдено без помилок і пропусків.**

- 21 перевірка початкової моделі прототипів.
- 17 перевірок кампаній: усі 18 карт проходяться з працюючими патрулями,
  пастками, дверима та плитами; бездумний прямий рух дає поразку на кожному
  одиночному рівні. Перевірені активація пастки під гравцем, спільна перемога,
  особисті інвентарі та неможливість обійти замкнені двері напарника.
- 13 перевірок інтерфейсу: меню, керування, пауза, блокування рівнів мишею
  та клавіатурою, запис і сортування топу, ім’я, відновлення прогресу,
  безпечне перенесення старих даних і малювання всіх карт.
- 2 перевірки формату `00:00:00` та обробки некоректних записів у топі.

`tests/playthrough.py` шукає безпечні кроки й очікування між контрольними
клітинками. Пошук використовує копії справжньої моделі, враховує час,
положення охоронців та фази пасток. Знайдені дії повторюються на початковій
моделі без вимкнення небезпек. У режимі на двох спершу активуються обидві
плити, потім гравці допомагають один одному проходити кольорові двері.
Кроки перевірки виконуються раз на 0,15 с, що повільніше за повтор руху в грі.

Короткий запуск обох режимів без дисплея:

```bash
SDL_VIDEODRIVER=dummy python main.py --prototype 09 --smoke-test
SDL_VIDEODRIVER=dummy python main.py --mode coop --prototype 09 --smoke-test
```

Кожен виконав 8 кадрів і завершився з кодом 0. Службовий режим перевірки
може намалювати закритий рівень, але звичайне меню не дозволяє його запустити.
Сітку закритих рівнів, спільну карту й локальний топ переглянуто на знімках.
Ручна гра на фізичній клавіатурі Windows й остаточна оцінка складності людьми
ще не виконані.
