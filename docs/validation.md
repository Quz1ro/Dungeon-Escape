# Перевірка роботи

Середовище перевірки: Linux, Python 3.12.14, Pygame 2.6.1.

## Автоматичні тести

```bash
python -m unittest discover -s tests -v
```

Результат: **24 тести пройдено**, без помилок і пропусків.

Перевірено:

- рух, стіни й межі карти;
- підбирання ключа та вихід із ключем і без нього;
- рух і розворот патруля, зіткнення з обох напрямків;
- пріоритет поразки при контакті з ворогом на ключі або виході;
- стани гри, перезапуск і закриття вікна;
- коректність карт і наявність шляху до перемоги у всіх трьох прототипах;
- обробку подій, малювання Pygame та українські символи.

Для перевірки прохідності тест перебирає кроки й очікування, враховуючи позицію
гравця, ключ та рух патруля. Знайдені дії відтворюються до перемоги також через
події клавіатури Pygame.

## Запуск без дисплея

```bash
SDL_VIDEODRIVER=dummy python prototypes/01_key_and_exit.py --smoke-test
SDL_VIDEODRIVER=dummy python prototypes/02_enemy_patrol.py --smoke-test
SDL_VIDEODRIVER=dummy python prototypes/03_dungeon_escape.py --smoke-test
```

Кожний прототип виконав 8 кадрів і завершився з кодом 0.
Для звичайної гри потрібен графічний сеанс без драйвера `dummy`.
Ручна перевірка на дисплеї та на інших операційних системах ще не проведена.
