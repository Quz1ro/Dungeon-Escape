# Перевірка роботи

Середовище: Linux, Python 3.12, Pygame 2.6.1, SDL `dummy`.

```bash
python -m unittest discover -s tests -v
```

**41 тест пройдено без помилок і пропусків.**

- 21 перевірка початкової моделі прототипів.
- 12 перевірок кампаній: усі 18 карт проходяться з підбиранням ключів
  і відкриттям дверей; наступний рівень має довший маршрут, не менше дверей
  та патрулів і менший інтервал кроку охоронця.
- 8 перевірок інтерфейсу: головне меню, дев’ять квадратів у сітці,
  вибір мишею та клавіатурою, незалежні й одночасно утримувані кнопки
  двох гравців, пауза, наступний рівень, прогрес і зміна розміру вікна.

Для проходження тест відтворює маршрут по сусідніх клітинках із працюючими
правилами дверей, ключів і патрулів. Після першого виходу в режимі на двох
гра триває, після другого — перемога. Патрулі розміщені у бічних проходах:
основний шлях не перекривається охоронцем без можливості обійти його.

Короткий запуск обох режимів без дисплея:

```bash
SDL_VIDEODRIVER=dummy python main.py --prototype 09 --smoke-test
SDL_VIDEODRIVER=dummy python main.py --mode coop --prototype 09 --smoke-test
```

Кожен виконав 8 кадрів і завершився з кодом 0. Меню, сітку та поле гри на двох
також переглянуто на знімках Pygame. Ручна гра на фізичній клавіатурі Windows
і оцінка складності людьми ще не виконані.
