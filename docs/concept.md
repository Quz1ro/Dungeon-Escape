# Концепція гри

Dungeon Escape — лабіринт із видом зверху. Мета — знайти ключі, відкрити
замкнені проходи й дістатися виходу. Проєкт розрахований на одного розробника.

Є два режими по дев’ять рівнів. В одиночному режимі керування — WASD або стрілки.
У локальній грі на двох гравець 1 використовує стрілки, гравець 2 — WASD.
Половини карти відокремлені стіною. Кожен проходить свій лабіринт, але результат
спроби спільний: потрібно дочекатися виходу обох.

Круглі ключі відкривають двері відповідного кольору й витрачаються.
Ключ-ромб дозволяє завершити рівень через власний вихід. Інвентарі не спільні.
Контакт із патрулем означає поразку обох; гравець на виході вже в безпеці.

Складність зростає за довжиною маршруту, кількістю дверей та патрулів і їхньою
швидкістю. Карти створюються за фіксованими початковими значеннями й не змінюються
між спробами. Перевірка з людьми потрібна для остаточного балансування.

Ігровий цикл: головне меню → режим → вибір рівня → гра → результат.
Після перемоги можна перейти далі; після поразки — повторити спробу.
Пауза зупиняє світ. Позначки проходження зберігаються окремо для двох режимів.

`campaign.py` містить карти й правила, `app.py` — інтерфейс Pygame.
Графіка складається з геометричних фігур; звук не додано.
